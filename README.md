# ev-charging-product-roadmap
Product roadmap and feature strategy project for EV charging app
This project outlines the strategic design of a mobile app for electric vehicle (EV) users in Germany. It includes a feature list, prioritization using MoSCoW, a 3-phase development roadmap, and success KPIs.

## Key Deliverables:
- Product Roadmap (MVP to Phase 3)
- Feature Prioritization (MoSCoW)
- KPI Framework
- Product Requirement Document (PRD)
- Extended description in `project-details.md`
